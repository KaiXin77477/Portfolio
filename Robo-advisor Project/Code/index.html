Robo-Advisor - Portfolio Optimizer

Welcome to our robo-advisor, designed to give inexperienced investors an idea of how their money could grow based on their initial investment amount, risk level, contributions and stock selection.

The programme bases its calculations on historical data obtained via the yfinance yfinance: yfinance is a Python library that provides access to historical market data from Yahoo Finance. It allows users to download price, dividend, and other financial data for a wide range of assets, which can then be used for analysis and modelling. library and generates forward-looking projections using statistical modelling. The code returns a list of possible weighted stocks (called a portfolio) based on the user's choice of investment sectors.

Please note: This tool does not account for external events such as wars, economic shocks, pandemics, or other market disruptions that can significantly impact asset prices.

As such, this tool should be used as a guide to possible outcomes, not a prediction of actual future performance.

Sharpe Ratio: Sharpe Ratio: This is a widely used metric to measure the performance of an investment, asset, fund or portfolio relative to the amount of risk taken. It is defined as the difference between the returns of the investment and the risk-free return, divided by the standard deviation of the investment returns. A higher Sharpe ratio indicates a better risk-adjusted return, meaning the investment provides a greater return for the additional risk taken. {{ result.sharpe_ratio }}

Sortino Ratio: Sortino Ratio: This is similar to the Sharpe Ratio but focuses only on downside risk, meaning it penalises negative volatility rather than all volatility. It provides a more targeted view of how well an investment performs when markets fall. The Sortino ratio is normally smaller than the Sharpe ratio as it only penalises downside volatility. {{ result.sortino_ratio }}
